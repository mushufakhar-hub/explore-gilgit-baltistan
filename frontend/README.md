# Explore GB frontend scaffold

Files created provide a Vite + React + TypeScript + Tailwind starting point.

Setup (from `frontend`):

```powershell
npm install
# then initialize Tailwind (if needed)
npx tailwindcss init -p

# dev
npm run dev
```

Env: set `VITE_API_BASE_URL` to the backend URL (e.g. `http://localhost:8000/api/v1`).
